# SkillForge

## Overview

SkillForge is a simulation-based platform where users practice real-world job tasks and generate verifiable proof of skill through structured work environments.

Instead of watching tutorials, users perform realistic tasks, receive evaluations, and progress through professional-grade simulations.

---

## Core Philosophy

SkillForge is built around a deterministic simulation engine.

The system controls:
- task progression
- evaluation
- scoring
- consequences
- portfolio generation

AI enhances realism through:
- contextual feedback
- manager-style messaging
- scenario enrichment

AI does not control grading or progression logic.
